# Фактична перевірка 0.1.0

Дата: 2026-10-20. Середовище: Linux, Python 3.12.14, SQLite 3.53.1.

- Editable-пакет успішно зібрано й встановлено у venv: `pip install --no-build-isolation --no-deps -e .`.
- Пройшли 7 unit-тестів: збереження листових текстів Persona, детермінізм, шляхи профілю, відмова від перезапису, відмова для некоректного XML та entities, персистентність пам'яті, фільтр проєкту, буквальний пошук, порожні поля й ліміти, код помилки CLI.
- Виконано CLI smoke: `doctor`, `init`, додавання й пошук української нотатки після повторного відкриття SQLite.
- `doctor` підтвердив: виконуваний файл Hermes відсутній. Hermes, LLM, API-провайдер та інструменти не запускались.
- Конфігурація CI додана, але GitHub Actions ще не запускались. Python 3.11/3.13 і Windows локально не перевірені.

Ці результати підтверджують роботу локальних утиліт; якість діалогів і сумісність із конкретною версією Hermes потребують наступного етапу.
