# ADR 0001: надбудова над Hermes без форку

Статус: прийнято для прототипу. Дата: 2026-10-20.

Потрібні впізнаваний характер, пам'ять, інструменти й можливість змінювати модель. Реалізація нового агентного циклу відкладе перевірку найважливішого — поведінки та збереження контексту.

Рішення: використовувати Hermes як зовнішній runtime, тримати Persona й власні компоненти в окремому репозиторії. Почати з документованих файлів профілю. Не оголошувати залежність на невідомий пакет із PyPI під схожою назвою; встановлення Hermes відбувається за upstream-інструкцією.

Альтернативи: власний цикл — більше контролю й значно більше супроводу; OpenClaw — можливий кандидат, якщо головною потребою стануть канали й оркестрація. Це рішення не є актуальним benchmark-порівнянням обох рушіїв.

Наслідки: швидший перевірний початок, але потрібні фіксація версії upstream та інтеграційні тести. Форк дозволений у майбутньому за наявності конкретного обмеження, яке неможливо розв'язати підтримуваним розширенням.
