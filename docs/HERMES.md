# Контракт інтеграції Hermes

Документацію перевірено 2026-10-20. Upstream швидко змінюється; конкретний commit для цього проєкту ще не зафіксовано. Немає реалізованого Python API-адаптера чи заяви про end-to-end сумісність.

| Дані | Шлях відносно HERMES_HOME |
| --- | --- |
| Основна особистість | `SOUL.md` |
| Профіль користувача | `memories/USER.md` |
| Компактна пам'ять | `memories/MEMORY.md` |

`AGENTS.md` належить робочому проєкту. Це не файл профілю. Для цього репозиторію він містить правила його розробки; запуск в іншому каталозі матиме інший проєктний контекст.

Hermes завантажує SOUL.md із HERMES_HOME. Наявні файли не замінюються стартовим шаблоном Hermes. Після зміни Persona або файлів пам'яті починай нову сесію. Розмір і фільтрація контексту залежать від upstream; перенесення XML у файл саме по собі не доводить, що кожна інструкція потрапила в модель.

## Перед першою реальною інтеграцією

1. Вибрати release або commit Hermes, записати SHA й фактичну версію Python.
2. Встановити Hermes окремо. Створити профіль командою Kohana і налаштувати його через Hermes.
3. Перевірити `hermes --help`, `hermes setup` і запуск у вибраній версії.
4. Підключити провайдера; виконати контрольний діалог українською та технічне завдання.
5. Перевірити завантаження Persona без небажаного обрізання і повторний запуск з пам'яттю.
6. Перед tool calls перевірити isolation, доступні каталоги та ризиковані дії.
7. Лише після цього реалізувати memory provider за API саме обраного commit.
